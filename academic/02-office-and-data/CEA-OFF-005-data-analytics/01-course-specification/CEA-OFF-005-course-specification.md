## 1. Identity

- **Duration:** 4 weeks · 8 sessions · 2/week · 105 min · **840 guided minutes**
- **Fee:** ₦50,000 · **Cohort:** max 15
- **Delivery:** On-site; Excel 2016+ or Google Sheets; printer for dashboard handout.

## 2. Description

From raw messy data to a decision. Students clean a realistic dataset, build pivot tables, choose
honest charts, and assemble an interactive Excel/Sheets dashboard with a one-page written analysis a
manager can act on. Intermediate course: comfortable with formulas required (OFF-002 completion or
equivalent).

## 3. Purpose

Data-literate staff are the difference between "we think sales dipped" and "sales dipped 14% in June,
driven by one SKU in three outlets; here's the chart". This course builds the whole pipeline working
end to end.

## 4. Audience

Working adults in operations/finance/admin/logistics · small business owners · analysts-to-be preparing
for roles · students targeting remote analytics gigs.

## 5. Entry requirements

OFF-002 (or equal: SUM, basic formulas, sorting, filtering) · willingness to argue with numbers politely.

## 6. Learning outcomes

1. Clean and validate a messy real-world dataset (text functions, de-dupe, missing values, rules).
2. Build lookups and conditional logic; combine datasets (XLOOKUP/VLOOKUP, IF, date/text handling).
3. Build pivot tables with grouped fields and calculated items; read summary statistics honestly.
4. Choose the right chart; build a clean interactive dashboard (slicers, conditional formatting).
5. Write findings and recommendations a manager can act on (trend, comparison, correlation vs causation, sample size honesty).

## 10. Assessment

| Component                                            | Weight |
| ---------------------------------------------------- | ------ |

| Workbook practicals                                  | 25%    |

**Critical gate:** dashboard functions (slicers/filters live, chart sourced from data, no hardcoded
numbers) — failure = reassess once.

## 11. Critical behaviors

Correlation never sold as causation; sample size named; raw data never overwritten (working copy rule);
misleading chart forms rejected on sight.

## 12. Learning barriers

Formula-on-top-of-formula intimidation; overfitting the chart (chartjunk); storyless dashboards.

## 13. Delivery

Real messy datasets (Grace Stores sales, clinic roster). Instructor demos live; students build in parallel.

## 14. Quality assurance · 15. Resources · 16. Completion

Pilot review; datasets versioned; instructor guide keys calibrated. Resources: machines, datasets,

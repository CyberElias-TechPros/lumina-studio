**Keyboard & mouse**

- **Click / left-click** — press the left mouse button to select or activate.
- **Right-click** — press the right button to open the context menu (options for the item).
- **Double-click** — two quick left clicks; opens files and programs.
- **Drag and drop** — hold the left button, move, release; moves the item.
- **Scroll** — turn the wheel to move a page up and down without clicking.
- **Home row** — the anchor row for typing: A S D F (left hand), J K L ; (right hand).
- **Modifier key** — a key that changes another key's meaning: Shift, Ctrl, Alt.
- **Caps Lock** — toggles capital letters; the small LED on the key shows it is on.
- **Shortcut** — a key combination that does a command instantly, e.g. Ctrl+C = copy.
- **WPM** — words per minute; five characters count as one word.

**The machine**

- **Hardware** — the physical parts of the computer. **Software** — the programs that run on it.
- **System unit / CPU** — the box containing the processor, memory, storage and ports.
- **Monitor** — the screen. **Display** — what the screen shows.
- **Peripheral** — an external device: printer, scanner, external drive, webcam.
- **Operating system (OS)** — the master program: Windows. It manages everything else.
- **Boot** — the start-up process, from power to usable desktop.
- **Desktop** — the home screen after login: icons, wallpaper, taskbar.
- **Taskbar** — the bar at the bottom: Start, pinned programs, clock, notifications.
- **Window** — the rectangle an application occupies; resizable, movable, closable.
- **Application** — a program: Notepad, File Explorer, Chrome, Word.
- **Icon** — a small picture that opens something when double-clicked.
- **RAM / memory** — the computer's working space; more memory, smoother work (never open it).
- **Storage** — where files live permanently: the C: drive inside the machine, or a USB drive.

**Files and folders**

- **File** — a single stored item with a name and an extension.
- **Folder** — a container for files and other folders.
- **Extension** — the part of the filename after the dot; tells you the file type (.pdf, .docx).
- **Path** — the file's address: drives and folders leading to it (`C:\Users\…\file.txt`).
- **Recycle Bin** — the holding area for deleted files; restore brings them back.
- **USB drive** — removable storage plugged into a USB port; eject before removing.
- **Download** — copying a file from the internet onto your machine.
- **Upload** — sending a file from your machine to a website.

**The internet**

- **Browser** — the program that shows websites (Chrome, Edge, Firefox).
- **Address bar** — the box showing where you are; also accepts a typed web address.
- **Tab** — one page inside the browser; several can be open at once.
- **Bookmark** — a saved shortcut to a website (Ctrl+D).
- **Search engine** — the service that finds pages for your words (Google, Bing).
- **URL / link** — the address of a page or a file on the web.
- **Email** — electronic mail; an account you create with an address and password.
- **Attachment** — a file sent with an email.
- **Cloud storage** — files kept on the provider's servers, reachable from any device.
- **Phishing** — a fake message tricking you into revealing data or sending money.
- **MFA (2FA)** — multi-factor authentication: a second proof at sign-in, besides the password.
- **Strong password** — 12+ characters, mixed types, unique to that account.

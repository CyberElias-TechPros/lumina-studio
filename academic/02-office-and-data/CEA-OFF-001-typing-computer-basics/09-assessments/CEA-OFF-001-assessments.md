All four knowledge checks: five questions, in session, self-marked, 2.5% each. Marking: full
correct = 2.5, partially correct = 1.5, attempt = 0.5, blank = 0.

## Knowledge check 1 — Session 1

1. Name three hardware parts and one peripheral.
2. What is the difference between sleep and shut down?
3. Where is the Start menu, and what does it open?
4. What should you never do to “turn off” a computer in normal use?
5. What is a window — name two things you can do with one.

**Answers:** 1) e.g. monitor, keyboard, mouse; peripheral e.g. printer. 2) Sleep keeps the
session in memory for fast wake; shutdown closes all programs and powers off fully. 3) Bottom-left button; opens applications, search, settings and power. 4) Hold the power button (except absolute emergency / instructor instruction). 5) A window is an application's work area; move / resize / minimise / maximise / close.

## Knowledge check 2 — Session 2

1. What are the three mouse click types and what does each do?
2. Which keys do your index fingers rest on, and which finger types `;`?
3. What does Caps Lock do, and how do you know it is on?
4. What does Ctrl+Z do? Give a real situation.
5. What is accuracy, and why does it matter more than raw speed?

**Answers:** 1) Left = select/activate; right = context menu; double-click = open. 2) F and J; right pinky types `;`. 3) Toggles capital letters; the key's LED lights. 4) Undo; e.g. restoring a paragraph deleted by mistake. 5) Correct characters ÷ all typed;
wrong characters must be retyped, costing more time.

## Knowledge check 3 — Session 3

1. What is a path? Read `D:\Portfolio\design\flyer.png` aloud.
2. What does F2 do? What does Ctrl+Shift+N do?
3. What is the Recycle Bin, and name two ways files bypass it.
4. Why must you eject a USB drive?
5. Name two red flags in a download link.

**Answers:** 1) The full location address of a file; D drive → Portfolio → design → flyer.png. 2) Rename; new folder. 3) Holds deleted items for restore; Shift+Delete and USB deletion bypass. 4) Windows caches writes in memory; eject flushes them so no corruption occurs. 5) Unexpected `.exe`/`.zip` extension, mismatched name vs content, pressure language, unknown
sender, impossible promise ("free ₦…"), link not matching the claimed site.

## Knowledge check 4 — Session 4

1. What makes a password strong? Give an example pattern you can remember.
2. What is an attachment, and how do you download one safely?
3. Name three scam red flags.
4. Why should you never click a link in a "your account will close" email?
5. Where do files stored "in the cloud" physically live, and what does that protect you from?

**Answers:** 1) 12+ characters, mixed case/digits/symbols, unique — e.g. three random words +
digits + symbol. 2) A file sent with an email; open only after checking sender and extension;
download saves a copy locally. 3) Urgency; odd/mismatched sender or link; credential request
(any three of: spelling errors, "too good to be true", pressure). 4) It leads where the attacker
wants — your credentials go to a fake page. 5) The provider's data centres; protects against
device loss/theft and enables sharing by link.

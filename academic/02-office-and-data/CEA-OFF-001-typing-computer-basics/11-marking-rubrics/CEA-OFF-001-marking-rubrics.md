## 1. Final project rubric (P1–P9)

Each of the nine behaviours: **2 = yes, competent · 1 = partial/with prompts · 0 = not yet**.
Convert raw to 40% weight; gates P1, P3, P6 must be ≥ 1.

| P   | Behaviour                                       | 2                     | 1                          | 0                      |
| --- | ----------------------------------------------- | --------------------- | -------------------------- | ---------------------- |
| P1  | Power on & login (strong password)              | Independent           | Slow / hints               | Cannot                 |
| P2  | Create & name folder correctly                  | Independent           | Name errors                | Cannot                 |
| P3  | Save note into folder                           | Independent           | Wrong location, corrects   | Cannot find saved file |
| P4  | Search & locate official file                   | Independent           | Needs hints                | Fails                  |
| P5  | Verify download (name/extension)                | Checks before opening | Opens without check        | Cannot tell            |
| P6  | Email with correct recipient + attachment, sent | Independent           | Wrong field, self-corrects | Cannot                 |
| P7  | Confirm in Sent folder                          | Checks                | Needs prompt               | Cannot                 |
| P8  | Locate sent mail later                          | Independent           | Struggles                  | Cannot                 |
| P9  | Sign out / safe shut down                       | Independent           | Needs reminder             | Incorrect method       |

**Conversion:** 18–15 → 40/40 · 14–11 → 32/40 · 10–7 → 24/40 · 6–1 → ≤16/40 · gates failed → 0.

**Show and tell (10%):** 10 = explains every step and reasons; 7 = explains steps; 5 = partial;
≤3 = cannot explain what they did (suggests rote copying; revisit with feedback).

## 2. Workbook practical exercises (25%)

Per activity, instructor ticks signed completion. Quality matters: spot-check one activity per
student per section. Full completion all sections → 25. Missing ≤2 activities → 20. Missing 3–5
activities or persistent quality issues → 15. Minimal completion → ≤10.

## 3. Assignments (15%)

A1 5 · A2 5 · A3 5. Full / on-time with correct evidence = 5; half = 2.5; missing = 0. Late ≤7 days
= half.

## 4. Knowledge checks (10%)

Per check (2.5 max each): full = 2.5 · partially correct = 1.5 · attempt = 0.5 · blank = 0. Chart
to 10.

## 5. Calibration notes (for moderation)

- Award 2 only when the behaviour is genuinely unaided. Re-reading a step to the student is a
  prompt and drops the criterion to 1.
- A student who completes everything but narrates nothing scores ≤ 24/40 + low show-and-tell.
- Hygiene: no marks for effort alone anywhere in this course; effort shows up in the portfolio.
- Record each cohort's mark distribution in the moderation file; discuss >15-mark swings between
  two instructors on the same script.

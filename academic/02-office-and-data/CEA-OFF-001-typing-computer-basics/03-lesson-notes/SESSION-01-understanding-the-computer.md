**1 — Learning outcomes**

By the end of this session you will be able to:

1. Name the main parts of a desktop and laptop computer and say what each part does.
2. Turn a computer on and off correctly using the power button and Start menu.
3. Log in and log out of Windows with your own account.
4. Recognise the desktop, the taskbar and the Start menu, and open and close an application.

**2 — Prerequisite knowledge**

None. This is the first session of your first course. If you have used a phone before, you are
more prepared than you think — a computer is the same idea with a bigger screen and more ways to
arrange your work.

**3 — Introduction**

Imagine you are asked to “just send this letter”, and everyone in the office expects you to know
how. The computer is now the default tool of every job in Nigeria — offices, shops, churches,
schools, NGOs, hospitals. Nobody is born knowing it either. This session ends the mystery. By the
last minute of class, you will have switched a machine on and off properly, signed in, and opened
and closed a program. That is a real, testable skill, and you will practise it until it is boring.

**4 — Key concepts**

- **Hardware** — the physical parts you can touch. **Software** — the instructions the hardware runs.
- **Monitor** — the screen. What it shows is called the **display**.
- **System unit / CPU** — the “brain” box (or the base of an all-in-one); holds the processor,
  memory, storage and ports. You never open it.
- **Keyboard** — the typing part. **Mouse** — the pointing part.
- **Power supply** — the electricity entry; the cable connects the computer to the wall.
- **Peripherals** — extra devices: printer, speakers, webcam and USB ports for external drives and
  flash drives.
- **USB port** — the flat rectangular socket used to plug in flash drives, keyboards, mice and more.
- **Operating system (OS)** — the main software that runs everything else; CEA uses **Windows**.
- **Desktop** — the home screen after login: wallpaper, icons, taskbar.
- **Taskbar** — the strip across the bottom: Start button, pinned apps, clock, Wi-Fi and sound icons.
- **Window** — the rectangle an application opens in; it can be moved, resized, minimised, maximised.
- **Application (app)** — a program: Word, Excel, Chrome, Notepad, File Explorer.

**5 — Instructor demonstration**

The instructor will (you watch, then repeat):

1. Locate the power button on the system unit and the monitor; identify the power cable and
   display cable; check the back of the unit and name each port you see (USB, HDMI, power).
2. Power on: press the system-unit button, wait for the desktop to load completely.
3. Log in with your practice account (username and password written on your card). Point out the
   password-mask dots.
4. Tour the screen: wallpaper, icons, taskbar, Start button, search box, clock, notification area.
5. Open Notepad from Start → type one sentence → open File Explorer → minimise, maximise, close.
6. Log out (Start → account icon → Sign out) and show the difference between sleep, shut down
   (Start → Power → Shut down) and simply holding the button (never do this unless forced).
7. Power the monitor off and the system unit on again; explain "on/off order".

**6 — Guided practice**

Working on your machine with the instructor beside you:

1. With a partner, name each hardware part out loud, then swap and repeat.
2. Power on from cold; log in; identify five desktop icons by name.
3. Open Notepad, type your name and today's date, minimise it, maximise it, close it.
4. Find the Start menu, the search box, the clock and the Wi-Fi icon — no mouse yet, just point.
5. Sign out, then sign back in.

**7 — Independent practice**

Do this alone; raise your hand only if you are stuck for more than two minutes:

1. Starting from the powered-off state, complete the full sequence: power on → login → open
   File Explorer → open Windows Settings → close both → sign out → shut down.
2. Draw the desktop from memory: where is the Start button? the clock? the taskbar? an icon?
3. Label your drawing with the words: monitor, desktop, taskbar, Start menu, window, icon.

**8 — Real-world example**

Grace Stores (a fictional Port Harcourt provision shop) keeps its price list on a shared computer.
When the owner “just presses buttons until something works”, the machine freezes and the day's
records are at risk. The proper habit — power on, sign in, open the program, do the job, close it,
sign out, shut down — is what the rest of this course builds. Every task in every other CEA course
starts and ends with this routine.

**10 — Common mistakes and troubleshooting**

- **Holding the power button to force off:** corrupts unsaved work. Use Start → Power → Shut down.
- **Powering the monitor only:** the system unit may still be on; check both.
- **Wrong password repeatedly:** count to five between tries; after three fails, check caps lock and
  ask the instructor — the academy can reset practice accounts.
- **Fear of clicking:** you cannot break the machine by opening programs. You can break nothing
  in this room that the instructor cannot restore. Click freely — that is how you learn.
- **Mouse confusion (buttons reversed):** some left-handed mice feel mirrored; tell the instructor
  and they will switch the setting or the hand.

**11 — Lesson summary**

- A computer = hardware (touchable) running software (instructions); Windows is the OS.
- Power on: system unit → monitor → login. Power off: Start → Power → Shut down.
- The desktop, taskbar and Start menu are your home base.
- A window holds every application; you can minimise, maximise, move and close it.
- Ask early, ask often — that is what the lab is for.

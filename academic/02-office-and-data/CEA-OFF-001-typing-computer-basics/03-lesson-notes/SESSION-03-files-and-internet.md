**1 — Learning outcomes**

By the end of this session you will be able to:

1. Explain the difference between a file and a folder, and read a file path.
2. Create, rename, move, copy, delete and restore files and folders.
3. Use a USB flash drive, including ejecting it safely.
4. Navigate a browser: address bar, tabs, back/forward, refresh, bookmarks and history.
5. Search the internet effectively and download a file safely.

**2 — Prerequisite knowledge**

Sessions 1 and 2. You should open Notepad and File Explorer without prompting and type a sentence
accurately. The session begins with a 5-minute typing log check.

**3 — Introduction**

"I saved it but I can't find it" has ended more Nigerian office days than any virus. Files are not
magic — they live in folders, folders live in drives, and every file has an address. Learn the five
file operations once, and use them for life. Then we add the other half of modern work: the
browser. By the end of this session you will find any document you created in the dark, and you
will tell a safe download from a dangerous one every time.

**4 — Key concepts**

- **File** — one stored item (document, photo, spreadsheet, song, program). **Folder** — a container
  holding files and other folders. Folders make organisation possible.
- **Filename & extension** — the name plus the part after the last dot: `.docx` Word, `.xlsx` Excel,
  `.pdf` fixed layout, `.jpg`/`.png` image, `.mp4` video, `.zip` archive. Extensions identify file
  types; show them (File Explorer → View → Show → File name extensions).
- **Path** — the file's full address: `C:\Users\YourName\Documents\CEA\notes.docx`, read as nested
  folders ending in the file. `C:` is the system drive; USB drives get D:, E: and so on.
- **The five file operations.** Create (right-click → New, or Ctrl+Shift+N) · Rename (F2) ·
  Move (Ctrl+X → Ctrl+V, or drag) · Copy (Ctrl+C → Ctrl+V) · Delete (Delete key → Recycle Bin).
- **Recycle Bin** — your safety net: restore returns deleted items to their original place.
  Exceptions: Shift+Delete and items deleted from a USB drive bypass the bin and are gone.
- **USB drive** — removable storage; always Eject before removing (write cache!).
- **Browser** — Chrome, Edge, Firefox, Safari. Address bar (where you type), tabs (Ctrl+T new,
  Ctrl+W close, Ctrl+Shift+T reopen), back/forward, refresh (F5), bookmark (Ctrl+D), history
  (Ctrl+H).
- **Download** — copy a file from the internet to your machine (goes to Downloads by default).
- **Upload** — send a file from your machine to a website (Choose File / Browse).

**5 — Instructor demonstration**

1. File Explorer tour: Quick Access, Documents, address bar, view options; enable file extensions.
2. Build a structure live: `Documents\CEA-2026\Week-02\Invoices`; create three `.txt` practice
   files in it; F2-rename one; move one via cut/paste; copy one; delete one — then Recycle Bin →
   right-click → Restore; watch it return.
3. Naming pattern on screen: `2026-11-16_GraceStores_quote-v1.pdf`; compare with `final2.pdf`;
   discuss why dates first.
4. USB: plug in, locate the drive letter, copy a practice file to it, Eject safely, reinsert,
   confirm the file arrived.
5. Browser: navigate to a safe site; open three tabs; search for "computer literacy Port Harcourt"
   and refine twice (quotes, minus-words, location); open history; add a bookmark.
6. Safe download: download a small official PDF; inspect extension; show where Downloads lives;
   show an example of a _suspicious_ download link and explain the red flags (unexpected .exe,
   pop-up origin, "free" claims).

**6 — Guided practice**

1. **Folder sprint (10 min):** in Documents, create `CEA-2026\Week-02\{Notes,Invoices,Images}` using
   Explorer and Ctrl+Shift+N; the instructor checks each structure.
2. **Five operations drill (15 min):** inside `Week-02\Notes` create `a.txt`, `b.txt`, `c.txt`;
   rename `b.txt` → `2026-11-16_renamed.txt`; move `c.txt` to `Images`; copy `a.txt` into
   `Invoices`; delete `a.txt` from `Notes` and restore from the Recycle Bin.
3. **USB round (10 min):** save a Notepad file titled `about-me.txt` to the USB drive; eject;
   re-insert; open it; confirm content.
4. **Browser bingo (20 min):** find and open three specific pages (academy site, an official
   government page, a news page); bookmark one; show history; close and reopen the tab.

**8 — Real-world example**

A small Port Harcourt clinic lost six months of appointment records when staff saved everything to
the Desktop and the laptop was stolen. One habit would have saved them: a top-level folder with
sub-folders, files named by date, and a USB backup ejected properly. You are building that habit
today, in one session, before the stakes ever exist.

**9 — Knowledge check 3**

1. What is a path? Read `D:\Portfolio\design\flyer.png` aloud.
2. What does F2 do? What does Ctrl+Shift+N do?
3. What is the Recycle Bin, and name two ways files bypass it.
4. Why must you eject a USB drive?
5. Name two red flags in a download link.

**10 — Common mistakes and troubleshooting**

- **Saving everything to Desktop:** the desktop is a workbench, not a warehouse. Create folders.
- **"New folder (2)" everywhere:** name folders immediately after creating them.
- **Deleting vs moving:** moving = relocate; deleting = Recycle Bin. When unsure, copy first.
- **USB corruption:** always Eject; if "drive in use" appears, close the open file, not the warning.
- **Wrong downloads:** check the extension before opening; `.exe`/`.msi` from the internet are not
  a PDF, however polite the page looked. Delete and ask the instructor.
- **Browser says "not secure":** do not enter passwords or card data on such pages; leave.

**11 — Lesson summary**

- Files live in folders; folders live in drives; the path is the address.
- Five operations: create, rename, move, copy, delete — plus restore from the bin.
- Name files `YYYY-MM-DD · subject · version`.
- Eject USB before removal. Check extensions of downloads.
- The browser is a workplace tool: tabs, bookmarks, history, safe searching.

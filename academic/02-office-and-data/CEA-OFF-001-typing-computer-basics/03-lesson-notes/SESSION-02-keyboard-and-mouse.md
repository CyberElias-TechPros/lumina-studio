**1 — Learning outcomes**

By the end of this session you will be able to:

1. Perform the core mouse actions: left/right click, double-click, drag-and-drop, scroll.
2. Name the key groups on a keyboard: letters, numbers, function keys, modifiers and navigation keys.
3. Use modifier keys correctly — Shift, Ctrl, Alt, Caps Lock, Enter, Backspace, Delete, Spacebar,
   arrow keys, Home/End.
4. Apply the correct home-row finger placement and type 15+ WPM at 90%+ accuracy (stretch: 25 WPM).

**2 — Prerequisite knowledge**

Session 1 (all of it). You must be able to log in and open Notepad unaided. Session 2 begins with a
three-minute "power drill" to check exactly that — if it is shaky, we fix it first.

**3 — Introduction**

Watch your phone for a minute: your thumbs already know where every letter is without looking. The
keyboard is the same skill — _muscle memory_. Nobody types fast because they see the keys; they
type fast because their fingers learned the map. Today we install that map properly: correct
position, correct fingers, deliberate practice. By the end of this course, typing is not something
you do — it is how you think onto the screen.

**4 — Key concepts**

- **Mouse actions.** Left click = select/activate. Right click = context menu. Double-click = open.
  Drag-and-drop = move something by holding the left button. Scroll wheel = move the page up/down.
- **Keyboard layout.** Left block: function keys (F1–F12), letters (QWERTY), numbers row (1–0),
  Tab, Caps Lock, Shift, Ctrl, Alt, Spacebar, Enter, Backspace, Delete, arrows, Home/End.
- **Home row.** A–S–D–F (left hand) and J–K–L–; (right hand). Thumbs rest on the spacebar.
  Every other key is reached from home row and returns to it.
- **Modifier keys.** Shift = capitals and symbols. Ctrl = shortcuts ("control"). Alt = menu access
  ("alternate"). Caps Lock = toggle capitals (watch the indicator light; it surprises everyone once).
- **Shortcuts you now know.** Ctrl+C (copy), Ctrl+X (cut), Ctrl+V (paste), Ctrl+Z (undo), Ctrl+S
  (save), Ctrl+P (print), Alt+Tab (switch windows), Ctrl+W (close window), Ctrl+A (select all).
- **WPM and accuracy.** Words per minute counts five characters as one word. Speed without
  accuracy is useless — a fast wrong letter is slower than a slower right one because you retype.

**5 — Instructor demonstration**

1. **Mouse lab.** The instructor demonstrates each action on screen projected; students replicate
   on their machines: left click the Start button; right-click the desktop for the context menu;
   double-click the Recycle Bin; drag a desktop icon into a new position; scroll a Notepad window.
2. **Keyboard map.** Point out letters (left hand QWET zone vs right hand), numbers row, Enter,
   and the modifiers in the bottom corners. Locate F, J (the bumps), and the spacebar.
3. **Finger placement.** Both hands on home row, fingers slightly curved, wrists floating.
   Index fingers on F and J. Tap keys diagonally (return to home each time).
4. **First drill.** `fff jjj fff jjj fjfj fjfj` then `asdf jkl;` slowly, watching NOT the keyboard.
   Emphasise: look at the screen or the card, never down at the keys.
5. **Shortcut drill.** In Notepad: type a sentence → select it with the mouse → Ctrl+C → new line →
   Ctrl+V. Then Ctrl+Z to undo. Feel how a shortcut replaces three menu visits.
6. **WPM baseline.** Students take a 2-minute baseline typing test (untimed pressure-free) to see
   today's starting speed and accuracy. Recorded on the workbook log — it is for you, not a grade.

**6 — Guided practice**

1. Mouse obstacle course (5 min): open three windows, switch between them, move and resize, close
   all — without using Alt+Tab until the last round (then compare).
2. Home-row anchoring (10 min): place fingers, close eyes, find F and J by touch. Repeat until
   instant.
3. Drill set A (15 min): `asdf jkl;` → `as df jk l;` with spaces; letters added one at a time in
   order e–i–o–u. Slow, even rhythm beats fast, uneven tapping. The instructor circulates and
   corrects finger assignment.
4. Shortcut chain (10 min): open Notepad, type "Cyber Elias Academy", select all (Ctrl+A), copy
   (Ctrl+C), paste twice (Ctrl+V ×2), undo once (Ctrl+Z), save (Ctrl+S) as `session2.txt` on the
   Desktop.

**7 — Independent practice**

1. **Drill set B (15 min)** from the workbook: `g h t y n m` added, then `r u`, then full alphabet
   sentences: “the cat sat on the mat” typed repeatedly, then “she sells sea shells…”.
2. **Accuracy check:** take a 1-minute typing test; record WPM and accuracy in the log.
3. **Self-assessment:** on a scale 1–5, rate (a) mouse control, (b) finding keys without looking,
   (c) modifier awareness — and write one sentence on what you will drill this week.

**8 — Real-world example**

A church secretary typing the weekly bulletin from a Word document is not paid to hunt keys —
they are paid to produce the bulletin. Two volunteers type the same 60-word paragraph: one at
18 WPM with errors, one at 35 WPM clean. The second finishes in under two minutes and goes to help
with chairs. Same keyboard, same alphabet; the difference is deliberate home-row practice.

**9 — Knowledge check 2**

1. What are the three mouse click types and what does each do?
2. Which keys do your index fingers rest on, and which finger uses `;`?
3. What does Caps Lock do, and how do you know it is on?
4. What does Ctrl+Z do? Give a real situation.
5. What is accuracy, and why does it matter more than raw speed?

**10 — Common mistakes and troubleshooting**

- **Looking down at the keys:** the single biggest cause of slow typing. Cover the keyboard with the
  card if needed; retrain the fingers, not the eyes.
- **Wrong finger for a key:** faster to relearn now than to perpetuate; instructor will reset your
  finger map on request.
- **Caps Lock surprises:** if everything comes out capitalised, press Caps Lock once — the small LED
  on the key tells you its state.
- **Pain or tension:** wrists must float, shoulders down, breaks every 15 minutes; report pain —
  we stop the drill, no heroics.
- **Mouse grip and double-click speed:** some mice are tuned fast; Windows Settings → Bluetooth &
  devices → Mouse slows the double-click threshold. Say so rather than struggle.

**11 — Lesson summary**

- Mouse: left = select, right = context, double = open, drag = move, wheel = scroll.
- Keyboard map: letters centre-left, numbers above, modifiers at the edges, spacebar centre.
- Home row A–S–D–F | J–K–L–; — fingers always return there.
- Accuracy before speed; drills little and often.
- Shortcuts are multipliers: Ctrl+C/V/Z/S, Alt+Tab.

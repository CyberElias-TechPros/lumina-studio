**Do not distribute.** Keys in Section 7.

## 1. What this course is

Habit transplant, not software tour. Students leave with a system they keep: inbox rules, folders,
naming, backup. The strongest predictor of success is S4's live restore moment — orchestrate it carefully.

## 2. Preparation

Machines with browsers; class sandbox Google accounts (created in advance; passwords printed sealed)
so no student is blocked at sign-in; the messy-folder/USB rescue kit; printed reference cards;
projector; class shared calendar.

## 3. Delivery model

105 min: 0–10 hook · 10–25 teach · 25–45 demo · 45–70 guided · 70–95 solo/final · 95–110 KC · 110–120 close.

## 4. Failure points

- S1: link shared as "edit" publicly — make the link-switch drill non-negotiable.
- S2: collecting fewer than 5 responses — seed classmates as respondents.
- S3: filters too narrow (nothing matches) — test each filter against 3 real messages live.
- S4: students confuse sync with backup at the exact moment of the assessed restore — rehearse the distinction verbally at least twice.

## 5. Assessment guidance

A1: Doc with resolved comment thread (instructor thread mandatory). A2: ≥5 real rows in linked Sheet +
3 one-line findings. Final (observed): P1–P6 sheet; the restore is the gate — accept any one file, but
it must be produced from cloud, not from local disk, in front of you.

## 6. Equity & access

Free Google accounts only; mobile-first students may drive everything from a phone if they lack a laptop;
larger-print cards available.

## 7. Knowledge-check keys

KC1: 1) Viewer/Commenter/Editor. 2) Publicly readable by anyone with the URL. 3) File ▸ Version history. 4) Suggestions are proposed; direct edits change immediately. 5) Auto-recalc; sorting/filtering.
KC2: 1) 30 + 10 min. 2) Timestamp + one row per submission, a column per question. 3) Incomplete rows poison stats. 4) Invitees assume their own locale time. 5) Any two valid question types.
KC3: 1) Leaves inbox; still searchable. 2) Label = tag on message (multi); folder = single home. 3) subject:receipt or subject:invoice (or equivalent). 4) Off-by-default; batch at set times. 5) Recurring identical replies.
KC4: 1) Sync mirrors (deletes both ways); backup is independent retained copy. 2) Alpha sort = chronological sort. 3) e.g. Area → Year. 4) Trash, 30 days. 5) Downloads empty · star today's · fix one filename · monthly backup check.

## 8. Expected outputs & calibration

S3: inbox counts visibly drop on screen. S4: trees shown on projector for two volunteers (names hidden);
gate restore witnessed and signed. First pilot: instructors agree on what counts as "one file restore"
(any personal file is fine — must come from cloud).

## 9. Rubric (0–4)

0 cannot · 1 heavy prompts · 2 completes with errors · 3 unaided, clean · 4 unaided + teaches the habit back. Gates: live restore absolute.

## 1. Identity

- **Title:** Digital Productivity · **Department:** Office & Data · **Level:** Absolute beginner
- **Duration:** 2 weeks · 4 sessions · 2/week · 105 min · **420 guided minutes**
- **Fee:** ₦30,000 · **Cohort:** max 15
- **Delivery:** On-site; machines with browser; free Google accounts provided for class practice

## 2. Description

The personal productivity stack most modern offices assume every employee has arrived knowing:
Google Workspace (Docs, Sheets, Slides, Drive, Calendar, Forms), Gmail managed like a professional
(labels, filters, archive vs delete), a folder structure with a naming convention that scales,
cloud backup done correctly, and a working recovery path for lost files.

## 3. Purpose

Employers lose hours to misfiled documents, flooded inboxes and "I never received the form". This
course installs the habits once, correctly, with a real working system the student keeps afterwards.

## 4. Audience

Absolute beginners; students and job-seekers; SME owners and staff; anyone whose computer is "a mess";
Google Workspace-first organisations (schools, NGOs, startups).

## 5. Entry requirements

Basic computer literacy (CEA-OFF-001 or equivalent). Free Google account created in class if needed.

## 6. Learning outcomes

1. Work competently in Google Docs, Sheets, Slides and Drive, including sharing and permissions.
2. Collect data properly with Google Forms wired to Sheets.
3. Build an inbox system: labels, filters, rules, archive discipline, templates, signature, notifications.
4. Build a folder structure + naming convention and back up critical files to cloud correctly.

| Component                                                                  | Weight |
| -------------------------------------------------------------------------- | ------ |

| Assignment A2 — Form collecting 5+ responses → Sheet pivot-lite            | 7.5%   |

**Critical gate:** backup verified — the student must produce one file restored from cloud during the final observation; gate failure = reassess once.

## 11. Critical behaviors

Share-links default "view" not "edit" without asking; naming before saving; archive before delete;
backup before format-of-anything; never personal Google account for client data without agreement.

## 12. Learning barriers

Password fatigue (multiple accounts) — password manager advice; notification anxiety — discipline drills.

## 13. Delivery

reference cards distributed.

## 14. Quality assurance · 15. Resources · 16. Completion

browsers, printed cards, shared class drive. Completion: attendance ≥ 3/4; gate passed; system filed/observed.

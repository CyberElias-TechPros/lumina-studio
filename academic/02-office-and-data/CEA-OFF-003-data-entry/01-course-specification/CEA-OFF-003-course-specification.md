## 1. Identity

- **Title:** Data Entry · **Department:** Office & Data · **Level:** Absolute beginner
- **Duration:** 2 weeks · 4 sessions · 2 sessions/week · 105 min each · **420 guided minutes**
- **Independent practice target:** 3–5 hours · **Fee:** ₦20,000 · **Cohort:** max 15
- **Delivery:** On-site, Windows machines with Excel and/or Google Sheets (free tier)

## 2. Description

Data entry is one of the most accessible entry points into office work in Nigeria — yet employers
report that untrained typists submit sloppy registers, misread phone numbers and scramble date
columns. This course builds professional-grade accuracy discipline: typing against a standard,
validating everything, de-duplicating and cleaning messy spreadsheets, naming files so a file can
be found in ten seconds, and finishing with a measured accuracy and speed report you can show in
an interview.

## 3. Purpose

Every organisation — banks, hospitals, schools, NGOs, churches, logistics — keeps records. The
bottleneck is never "can they type?" but "can they be trusted with the register?" This course
produces verifiable, measured entry competence with honest self-reporting.

## 4. Audience

- Beginners with basic computer literacy (CEA-OFF-001 or equivalent)
- Job-seekers targeting data-entry / clerical / back-office roles
- NYSC corps members assigned to administrative units
- Anyone preparing for an accuracy test at a recruitment stage

## 5. Entry requirements

- CEA-OFF-001 or equivalent (typing ≥ 20 WPM, file basics)
- A practice machine; Excel 2016+ or Google Sheets (free)
- No prior spreadsheet experience needed — taught from zero

## 6. Learning outcomes

By the end, the student can:

1. Enter data at a professional accuracy rate (≥ 98% on measured tests) and explain their own error profile.
2. Structure a growing spreadsheet correctly: headers, data types, formats, tables, locked totals.
3. Sort, filter, de-duplicate and find-and-replace to clean a realistic messy dataset.
4. Name and organise files and folders so any record is retrievable instantly.
5. Produce an honest accuracy and speed progress report.

## 9. Practical exercises

- Raw register keyboard entry (guided): clean a 60-row church-members list.
- Format lab (guided): dates DD/MM/YYYY, phone numbers as text, names Title-cased.
- De-duplication drill (independent): 200-row customer sheet with planted duplicates.
- Validation gauntlet (independent): cross-check a form against a source sheet; count planted errors.
- File-organisation challenge (guided): deliver a client-ready folder tree + README.

## 10. Assessment

| Component                                       | Weight |
| ----------------------------------------------- | ------ |
| Knowledge checks (4 × 5 questions)              | 10%    |
| Workbook practicals (S1–S4)                     | 25%    |
| Assignment A1 — cleaned register + short report | 15%    |
| Accuracy & speed final (observed)               | 40%    |
| Show-and-tell — error report walk-through       | 10%    |

**Critical gate:** final measured accuracy ≥ 98% (max 2% error rate) with errors identified, else
reassessment once within 2 weeks. Speed is reported, not gated (honest reporting over speed theatre).

## 11. Critical behaviors

- Never types over a source while "correcting" it without a copy; always verifies against source.
- Names files with date-prefix conventions unprompted after S3.
- Flags contradictions with the client/source instead of guessing ("phone looks like landline without area code — please confirm").

## 12. Learning barriers

- **Perfection paralysis** (stalls, re-types obsessively): drill "flag, don't fret" — mark suspect cells yellow, finish, report.
- **Copy-paste where transcription is required**: some assessments must be typed by hand; make the where-not-to-paste rule explicit.
- **Format blindness** (mixed dates, 01/02 vs 02/01): S2 drill until consistent DD/MM/YYYY is automatic.

## 13. Delivery

A4 paper drills + machines. Instructor models every drill slowly first. Sessions 3–4 run against
the clock but marking rewards accuracy over raw WPM.

## 14. Quality assurance

Pilot cohort reviewed against this spec; accuracy gates calibrated on real sheets; error-rate
measurement script kept instructor-side; reviewed each edition.

## 15. Resources

Academy machines with Excel/Sheets · practice datasets (messy register, planted duplicates,
validation forms) · printed drill sheets · stopwatch · instructor master answers.

## 16. Completion

Attendance ≥ 3 of 4 sessions; gate passed; workbook signed; portfolio: cleaned dataset PDF +
accuracy report. Certificate issued after instructor sign-off.

**Do not distribute.** Answer keys in Section 8.

## 1. What this course is

A discipline transplant: verified, structured, honestly reported record-keeping with spreadsheets as
the arena. Students arrive wanting "speed"; they leave trusting measurement and knowing their error
profile. Manage this identity shift explicitly from minute one.

## 2. Preparation

Office machines, Excel 2016+ or Google Sheets. Print: practice register cards, the S1 bad register,
S3 admission forms, S4 accuracy-report template, S4 KC slips. Load files on each machine:
`GraceStores-200-customers.xlsx`, `Church-register-messy.xlsx`, `GraceStores-dump-500.csv`,
`admission-forms-raw.xlsx`, `accuracy-report-template.xlsx`. Test projector for scans (S3–S4).

## 3. Delivery model

105 minutes: 0–10 review/warm-up · 10–25 teach · 25–45 demo · 45–70 guided · 70–95 independent/
assessment · 95–110 KC/marking · 110–120 summary. Pace on observable behaviour, not slides.

## 4. Session failure points

- **S1** Students type phone numbers as numbers ("0803…" drops leading zero live on screen — use
  this as the demo hook, every time).
- **S2** Sorting a single column without selecting the rest — scrambles rows in front of them;
  make them undo it, then teach Table-convert discipline.
- **S3** "I'll just fix it by eye" — the word "just" is a red flag; enforce EXACT helper cells.
  Students type "n/a" into unreadable cells — forbidden; yellow-flag only.
- **S4** Block A refusal/freezing under the timer — coach this as a simulation, not a judgment.
  Accuracy below 95%: stay with them, re-run the verify routine once, never lower the 98% gate.

## 5. Assessment guidance

Workbook signatures per box; S2 cleanup must show Table + zero duplicates; A1 register: spot-check
10 random rows for locale-uniform dates + text phones. Final sheet P1–P8… for this course use the
accuracysheet below. Gate (≥98%) cannot be compensated by speed or effort — reassess once at +2 weeks.

## 6. Equity & access

Colour-blind students: never use colour alone — yellow fill + note text ("?" in cell note).
Dyslexic students: pair the on-screen find-check (Ctrl+F) early. Large-print registers on request.
No internet required; all artefacts offline.

## 7. Classroom management

Timed blocks = silence + clear end signals. Seat students who type heavily apart from talkers.
Phones collected at S4 start for timed blocks.

## 8. Knowledge-check keys

KC1: 1) Record = row/entity; field = column/attribute. 2) Leading zeros; never computed on; Excel
strips zero. 3) Up to 10 wrong cells (2%) — e.g. 10 bad phone numbers. 4) Yellow-flag; never guess;
report unreadable. 5) Wrong data costs more than slow typing; speed on wrong habits multiplies errors.
KC2: 1) Software reads row 1 as field names — sorting/filter/Table anchor. 2) Format as Text first /
`'` prefix. 3) "Ade Lawal" (ends trimmed, inner double space stays). 4) Filter. 5) Select all columns
(or Table-convert) + back up.
KC3: 1) Source is evidence; must stay traceable. 2) Case & trailing-space differences. 3) Required /
format / range / list (any 3). 4) Yellow-flag each; complete the rest; report honestly. 5)
`2026-11-16-committee-updated-v3.docx`-style, date-prefixed, lower-case, hyphenated.
KC4: 1) ≥98% = ≤10 wrong cells of 500; recruitment standard. 2) EXACT catches case/trailing spaces
eyes miss. 3) dataset description / findings / actions / improvements (any 2). 4) Yellow-flag;
complete; never invent. 5) Honesty in tests; inflated numbers fail live recruitment tests.

## 9. Expected outputs & calibration

S1: every student re-derived the leading-zero failure live. S2: zero-duplicate cleanup screenshot on
screen. S3: validation-gauntlet scores recorded; find the pair who typo'd the most "mati" vs "mati"
— debrief laughter, then EXACT trick. S4: gate awards issued only with the measured table attached;
reports filed to cohort file.

## 10. Rubric (0–4)

0 cannot · 1 heavy prompts · 2 completes with errors · 3 unaided, ≥98% · 4 unaided, ≥99% + explains.
Gate is absolute: sub-98% = reassess, regardless of band elsewhere.

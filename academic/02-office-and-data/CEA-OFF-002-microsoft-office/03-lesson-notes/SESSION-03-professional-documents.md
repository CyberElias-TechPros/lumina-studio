**1 — Outcomes**
Set page size, margins, orientation; add headers, footers and page numbers; insert tables, images,
shapes and text boxes; add hyperlinks; structure a CV; build a simple certificate; print and export
to PDF.

**2 — Prerequisites**
Sessions 1–2. Formatting fluency expected.

**3 — Introduction**
A letter on Word with a footer and page numbers is a letter that survives printing, scanning and
filing. A CV with proper structure is the one recruiters read to the end. Today, your documents
graduate from homework to evidence.

**4 — Key concepts**
Page setup (A4 default, 1″ margins, portrait vs landscape), headers/footers (insert once, repeats
every page; different first page), page numbers (Insert → Page Number), tables (rows/cols, merge,
shade header row, borders), images (insert, resize via corners, alt text, wrap text), shapes &
text boxes (logo placeholders, callouts), hyperlinks (Ctrl+K), CV anatomy (name/contact → personal
statement → experience → education → skills → references line), certificate essentials (title, name,
course, date, signature, stamp area), print preview vs reality, PDF export fidelity.

**5 — Demonstration**
Build a one-page certificate top-to-bottom: landscape A4, border shape, title, recipient name in
accent, course line, date, signature line; save as PDF; then open the PDF and confirm layout
survived. Then a 2-line header/footer with page number on the circular from S2.

**6 — Guided practice**

1. Create a letterhead block (name, address, phone, email) using a table with hidden borders.
2. Insert a fake logo shape; add footer with page number right-aligned.
3. Table exercise: an inventory table for Grace Stores with shaded header row and 5 rows.
4. Export to PDF and reopen it.

**7 — Independent practice**
Design your own CV page in Word: name, contact, one-line personal statement, 3 sections with
headings (Experience, Education, Skills), footer with page number, printed.

**8 — Real-world example**
A school in Rumuola sends circulars without page numbers; parents lose the second page and blame the
school. A two-line footer fixes it permanently. The same CV that got Blessing no interview for 3
months started getting callbacks when she added a skills section and a one-page constraint.

**9 — Knowledge check 3**

1. Default A4 margins? 2. How to number pages from page 2? 3. Table: which row gets the shading?
2. Why PDF for sharing? 5. Three things every CV needs in order.

**10 — Common mistakes**
Portrait certificates (landscape reads better); images stretched (always corner-drag); footers
added to page 2 only (it repeats automatically); CV longer than one page at this level; PDF printed
at 115% scale clipping borders (set print scale 100%).

**11 — Summary**
Page setup first, then content. Tables for letterheads and inventories, footer page numbers always,
CV one page, certificates landscape, PDF to share, print preview to verify, 100% scale.

**12 — Assignment**
A1 PDF due and printed in class. 10% total.

**13 — Reflection**
If your CV page felt hard, our career talks help; Microsoft Excel starts next — bring a price list
or sales ledger (photos are fine).

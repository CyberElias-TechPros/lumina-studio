**1 — Outcomes**
Sort and filter data; convert ranges to Tables; compute basic percentages; use relative references;
build bar, pie and line charts; print a spreadsheet properly (fit to width, print area).

**2 — Prerequisites**
Session 4. Formulas and formatting are assumed.

**3 — Introduction**
Raw rows of numbers nobody reads are not information. Sorted, filtered, charted — now the data
talks. This session turns your sheet into a report a manager would act on.

**4 — Key concepts**
Sort A→Z / Z→A / multi-level (Data → Sort); filter (Data → Filter — dropdown arrows, top-N, text
contains); Tables (Ctrl+T — auto-format, structured references, auto-expanding totals); percentages
(`=part/total`, format %; increase/decrease % = (new-old)/old); relative vs absolute references
(A1 shifts when dragged, $A$1 stays — name the dollar sign as "fence"); charts (select data →
Insert → chart; bar for comparison, pie for parts-of-whole ≤6 slices, line for trend; title, axis
labels, legend); printing (Page Layout → size, orientation, print area, fit to 1 page wide, print
gridlines).

**5 — Demonstration**
Open the sales sheet from S4: convert to Table (Ctrl+T); sort by Total descending; filter to items
with qty ≥ 5; compute % of total column (=E2/$E$10 — point out the fence); build a bar chart
(top sellers), a pie chart (revenue share) and a line chart (sales over days); Page Layout → fit to
width one page; print preview; save PDF.

**6 — Guided practice**
Using a provided 12-row inventory dataset: students convert to Table, sort by reorder level, filter
out-of-stock rows, compute reorder percentages, build one chart, print to PDF landscape.

**7 — Independent practice**
Your own dataset (expenses, or Grace Stores inventory): Table-convert, one sort, one filter, one
% column with a fenced reference, one chart with title and labelled axes, print preview screenshot
plus PDF export.

**8 — Real-world example**
A tailor in New Benin kept stock counts on paper and ran out of Ankara mid-December at peak; the
same shop now sorts by stock level every Friday — the filter shows red rows, she reorders. One
formula grid saved her busiest month.

**9 — Knowledge check 5**

1. What does Ctrl+T create? 2. How to fence a reference? 3. Which chart for parts of a whole?
2. Sort vs filter — difference? 5. How to make a wide sheet print legibly?

**10 — Common mistakes**
Pie charts with 14 slices (group the rest into "Other"); unfenced totals producing 0.00% errors;
sorting only one column and scrambling rows; charts with no title/axes; printing a 6-column table
across 4 pages (fit to width); editing the Table header row text (structured references break).

**11 — Summary**
Table-convert before analysing. Sort for ranking, filter for subsets. Fence totals with $. Charts
with titles and labels. Print: landscape + fit to width + print preview always.

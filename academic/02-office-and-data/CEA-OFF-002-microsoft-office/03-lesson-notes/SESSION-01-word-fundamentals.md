**1 — Learning outcomes**
By the end you will be able to: open Word and understand the interface (ribbon, tabs, document area,
status bar); create and save a document with Save As; choose between .docx, .pdf and .txt; reopen a
saved document; select text; use copy/cut/paste and undo/redo; create a folder from inside Word.

**2 — Prerequisite knowledge**
Power on, login, File Explorer basics, mouse and keyboard confidence (CEA-OFF-001 level).

**3 — Introduction**
Every document you will write in this course — letters, CVs, reports, certificates — begins here:
an empty page that isn't scary because you know where everything lives. Ten minutes learning the
interface saves a lifetime of hunting for buttons.

**4 — Key concepts**
Ribbon & tabs (Home/Insert/Layout…), document area, status bar (page count, language, zoom), Save vs
Save As (F12), file formats (.docx editable, .pdf fixed for sharing, .txt plain), Quick Access Toolbar,
undo/redo (Ctrl+Z/Ctrl+Y), selection (click-drag, double-click word, triple-click line).

**5 — Instructor demonstration**
Open Word → blank document; tour ribbon groups; type a paragraph about your favourite food; Save As
to `Documents\CEA-2026\Office\` as `my-first-document.docx`; close; reopen from File Explorer by
double-click and from Word → Open; show PDF export path (File → Save As → PDF). Demonstrate selection
trio and Ctrl+C/X/V, Ctrl+Z/Y; create a new folder inside the Save As dialog (New Folder button).

**6 — Guided practice**
Partnered: open Word; identify the five interface parts aloud; type the paragraph; save it with Save
As; close and reopen; export the same document to PDF; rename the PDF from Explorer.

**7 — Independent practice**
Write a 3-paragraph introduction to yourself (name, where from, what you want from this course) in a
new document; save as `about-me.docx` in a new folder `CEA-2026\Office`; export PDF; close Word.

**8 — Real-world example**
Chidi, an NYSC corps member, lost three versions of his CV in one week because each save overwrote
the last with no dates. One habit fixes that: Save As, dated names (`2026-11-16_CV_Chidi-v1.docx`),
in a dated folder. You will never lose a document this way again.

**9 — Knowledge check 1**

1. Name three parts of the Word interface. 2. Save vs Save As? 3. Which format is fixed for sharing?
2. What does Ctrl+Z do? 5. Double-click selects ___; triple-click selects ___.

**10 — Common mistakes**
Saving to Desktop then losing it — always work inside `Documents\CEA-2026`; closing without saving
when prompted (read the dialog!); believing PDF is editable; selecting with the mouse when Shift+Arrow
is faster; panic pressing buttons — Ribbon tabs are labelled, read them.

**11 — Lesson summary**
Interface tour complete. Save early, Save As with dated names, PDF to share, reopen to verify.
Shortcuts: Ctrl+N/O/S/F12/Z/Y/C/X/V.

**12 — Assignment**
A0 (practice, not graded): recreate today's document at home or in open lab; bring questions.

**13 — Reflection & progress**
Can you find the Save As button without looking? If not, say so — Session 2 assumes it.

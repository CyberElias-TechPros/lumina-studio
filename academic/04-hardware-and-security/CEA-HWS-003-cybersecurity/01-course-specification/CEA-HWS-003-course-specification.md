## 1. Identity

- **Title:** Cybersecurity · **Department:** Hardware & Security · **Level:** Beginner
- **Duration:** 4 weeks · 8 sessions · 2/week · 105 min · **840 guided minutes**
- **Fee:** ₦50,000 · **Cohort:** max 15
- **Delivery:** On-site classroom; machines; safe sandbox examples only (no live attacks, ever)

## 2. Description

Practical defence-in-depth for the everyday digital citizen and the small business: CIA triad, risk
thinking, authentication done right, phishing-spotting drills, Wi-Fi/firewall/encryption basics, incident
response, policies — capped by a written security assessment of a fictional organisation.

## 3. Purpose

Nigeria loses billions yearly to fraud and weak hygiene — mostly preventable by boring, well-taught habits.
This course produces the person who doesn't click.

## 4. Audience

Office staff and SME owners · bank/fintech-adjacent admins · students entering security · anyone managing other people's data.

## 5. Entry requirements

Basic internet use; curiosity; no prior security knowledge.

## 6. Learning outcomes

1. Explain CIA, threats, vulnerabilities, risk and controls in professional terms and prioritisation language.
2. Build strong authentication: password managers, diceware-style passphrases, MFA everywhere, email hardening.
3. Spot phishing/social engineering/scams on sight with a 10-second checklist instinct.
4. Assess Wi-Fi, firewalls, encryption, HTTPS and account security; harden a home/shop setup.
5. Identify incidents, run basic response (disconnect, report, recover), and write the assessment report.

## 9. Practical exercises

CIA word-sorting (S1) · passphrase lab + manager setup (S3) · 40-message phishing sort (S4) · home router
hardening checklist (S5) · HTTPS inspection (S6) · tabletop incident walk (S7) · final assessment (S8).

## 10. Assessment

| Component                                                             | Weight |
| --------------------------------------------------------------------- | ------ |
| Knowledge checks (8 × 5)                                              | 10%    |
| Workbook practicals                                                   | 25%    |
| Assignment A1 — personal/home hardening audit with photos             | 15%    |
| Final project — organisation security assessment + improvement report | 40%    |
| Show-and-tell — top three findings to a board (role-play)             | 10%    |

**Critical gate:** final report must contain risk-ranked findings with owners and timelines — a list of fears is not an assessment; reassess once.

## 11. Critical behaviors

Assume breach, not blame · verify out-of-band · least privilege always · report fast, blame never · privacy and law respected (only fictional/lab targets).

## 12. Learning barriers

"It won't happen to me"; password fatalism; shame after clicking — classroom is judgment-free.

## 13–16. Delivery · QA · Resources · Completion

Safe-example repo curated; no live attack traffic; guest presenters (bank fraud unit) when available. Attendance ≥ 6/8; gate passed; report filed; feedback form before certificate.

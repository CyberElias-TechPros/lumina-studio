## 10–25 · Teaching block

**Transitions: almost never.** 95% is hard cuts and jump cuts. A wipe/spin/page-dissolve announces "I, the editor" — you are invisible machinery or you are fired.
Use cross-dissolve ONLY for time/place transitions; match-cut (similar shape across cut) is the pro's darling.
**Motion graphics.** Pop-in lower-third (subtle scale 90→100% + fade), animated word highlight SAMBA-synced (your accent colour), counter/stat cards for proof moments, logo bug minimal corner.
**Brand consistency.** Same accent, same font, same lower-third for every client video — a style frame saved beats reinventing every export.
**WhatsApp/format graphics.** Text must read at 480p 16KB WhatsApp forward quality — test the export at thumbnail size.

## 25–45 · Guided demonstration

Live: three transitions on one cut (cut / dissolve / spin) screened twice — class votes each time; spin exiled; one match-cut built (bowl → stadium crowd aerial); lower-third pop-in timed to 0.4s.

## 45–70 · Guided practice

Pairs: transition diet on each other's timelines — hunt every illegal wipe, replace with cut or match-cut; count pre/post; debrief.

## 70–95 · Independent practice

Solo: **one graphics pack** per piece — lower-third + accent-word set + end card; applied; consistent font/accent; exports verified at phone-thumbnail size. File to workbook.

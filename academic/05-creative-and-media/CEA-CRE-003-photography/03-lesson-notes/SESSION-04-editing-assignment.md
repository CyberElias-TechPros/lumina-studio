## 0–10 · Review & warm-up

Control drills screened — class picks best-framed per scene; note the quiet wins.

## 10–25 · Teaching block

**Editing order (don't skip).** (1) Cull first — delete 60% without mercy. (2) Straighten + crop (rule-of-thirds snap ON). (3) Exposure/brightness baseline. (4) Contrast — gently. (5) White balance — skin honest. (6) Highlights down / shadows up — recover, not invent. (7) Sharpness/clarity LAST, small; texture on food = yes, skin = no.
**Colour sanely.** Saturation +5 max before it screams; vibrance instead (lifts dull, protects skin); one consistent look per SET — batch copy settings, then tweak per frame.
**Batch consistency.** Edit one "hero" frame perfectly → sync settings across set → per-frame fixes only. Three clicks per photo, not thirty sliders.
**Export sizes.** Web/social: 1080px long edge, JPG q~80 (<500KB) · print: full res, sRGB, 300DPI at print size · keep originals + edits in `set/originals/` and `set/final/`.
**Assignment brief.** Set A (product/food, 6 frames) + Set B (event/portrait, 6 frames) — each with per-frame one-line decisions note.

## 25–45 · Guided demonstration

Projected lightroom-mobile/snapseed edit of a food frame: 20-second cull decision → straighten → exposure → WB → highlights → vibrance +10 → clarity +8; then SYNC to four siblings; export both trees; notes written.

## 45–70 · Guided practice

Pairs: edit a shared 10-frame product set with the hero-sync method; instructor circulates enforcing the ORDER; exports into folder tree; verify against each other.

## 70–95 · Independent practice (final project assembly)

Solo: finalise **Set A + Set B** (12 frames) with decision notes; folder trees; instructor signs off counts/sizes.

## 95–110 · Correction & check

KC4: (1) Cull percentage. (2) Edit order (three first steps). (3) Vibrance vs saturation. (4) Hero-sync method. (5) Web export spec.

## 110–120 · Course close

Certificate gate: all 12 frames student-shot this term. Portfolio: two sets + notes. Keep the cull habit — it's the skill forever.

## Answers — KC4

1. ~60%. 2) Cull → straighten/crop → exposure. 3) Vibrance protects skin and lifts muted hues; saturation hammers everything. 4) Edit one perfectly, sync, per-frame fixes. 5) 1080px long edge JPG ≤ ~500KB; print = full res sRGB.

**Do not distribute.** Keys in Section 7.

## 1. What this course is

Two weeks from "I take photos" to scrabbling for a sunset window. Assignments dominate; screens are grazed, not worshipped.
No phone left unused all session — hands-on every minute.

## 2. Preparation

Backdrops (3 colours), reflectors (2), clamp lamps + daylight bulbs, "Mr Spoon" still-life kits, sample cards, release forms, tablet as slideshow viewer for critiques.

## 3. Delivery model

105 min: 0–10 image verdict · 10–25 teach · 25–45 live demo · 45–70 shooting rounds · 70–95 edit bench · 95–110 KC · 110–120 close.

## 4. Failure points

- S1: centre-obsessed framing — rule-of-thirds grid overlay ALWAYS on during class.
- S2: ceiling bulb portraits — kill it physically; one lamp + reflector only.
- S3: HDR on faces — the waxy reveal demo is mandatory.
- S4: saturation 100 — vibrance-first rule; clarity ≤ +12 enforced by bench roaming.

## 5. Assessment guidance

A1 product six frames: edited per order chain, tree present. Final: 12 frames + notes; gate = provenance (no stock passed as student work; metadata/timestamps sanity check).

## 6. Equity & access

Cracked-screen loaners; settings sticky notes on each phone; large-print briefs; portraits only with release cards signed; shy students can shoot hands/food.

## 7. Knowledge-check keys

KC1: 1) Intersections not dead-centre. 2) Lines walk the eye in. 3) Premium space + focus. 4) Tilted horizons read as error. 5) Lens clean + background scanned + levelled.
KC2: 1) Front/side/back. 2) Hard = direct sun/bare bulb; soft = overcast/window. 3) First/last hour sun. 4) Foam board, sheet, sack, tinfoil-card. 5) Kill ceiling; one side source + bounce.
KC3: 1) Focus point + metering. 2) Slide to subject; wall doesn't deserve exposure. 3) Faces waxy; landscapes ok when static. 4) Finals raw / volume JPEG. 5) Timer 2s + elbows/wall.
KC4: 1) ~60% culled. 2) Cull → Straighten/crop → exposure (any order consistent). 3) Vibrance lifts dull, protects skin. 4) Hero sync. 5) 1080px ≤500KB; print full-res sRGB.

## 8. Expected outputs & calibration

S2: each pair produces front/side/back triptych. S4: both sets exist before screening; two assessors sign the provenance line.

## 9. Rubric (0–4)

0 unusable · 1 heavy prompts · 2 competent, amateur edges · 3 clean, intentional, unforced · 4 gallery-droppable. Gate: provenance.

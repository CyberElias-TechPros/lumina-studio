## 1. Identity

- **Title:** Graphic Design · **Department:** Creative & Media · **Level:** Beginner
- **Duration:** 4 weeks · 8 sessions · 2/week · 105 min · **840 guided minutes**
- **Fee:** ₦40,000 · **Cohort:** max 15
- **Delivery:** On-site; machines with Canva-class editor (free tier); printed reference posters; colour wheels

## 2. Description

Design judgment first, tools second: layout, hierarchy, colour, type, image, then the brief→export→revision
workflow real clients use — producing a mini brand package (logo, flyer, social post, business card) from
a real-ish design brief.

## 3. Purpose

Every church flyer, shop advert and WhatsApp graphic in Port Harcourt is a design judgement made by someone.
This course produces the someone who judges deliberately.

## 4. Audience

Beginner designers · SME owners doing their own materials · creators formalising · NGO/church media teams.

## 5. Entry requirements

Basic computer use; no art talent required (taught, not "gifted").

## 6. Learning outcomes

1. Judge and fix layout, hierarchy, contrast, alignment, balance, white space on sight.
2. Choose and pair typefaces; set readable, hierarchical text.
3. Produce print + digital artefacts to spec (DPI, colour mode, bleed awareness).
4. Work a brief → draft → corrections → sign-off → export pipeline like a professional studio.

## 9. Practical exercises

Fifteen-layout critique (S1) · font pairing duel (S2) · template-to-original (S3) · brand kit build (S4) ·
live flyer sprint (S5) · card print-test (S6) · brief-to-export drill (S7) · final package (S8).

## 10. Assessment

| Component                                                    | Weight |
| ------------------------------------------------------------ | ------ |
| Knowledge checks (8 × 5)                                     | 10%    |
| Workbook practicals                                          | 25%    |
| Assignment A1 — client-ready flyer + social set (from brief) | 15%    |
| Final project — mini brand package, presented under critique | 40%    |
| Show-and-tell — defend the logo choice against the room      | 10%    |

**Critical gate:** export spec compliance — print PDF with bleed/embedded fonts + PNG/JPG at platform pixels, delivered in the file tree requested (print/ vs web/) — failure = reassess once.

## 11. Critical behaviors

Critique work not people · two corrections in writing before touching · grids before gradients · export twice (print & web), always · fonts named, licences honest.

## 12. Learning barriers

Gradient addiction · clipart crowns · "like" as design feedback — every critique lands on reason.

## 13–16. Delivery · QA · Resources · Completion

Colour wheels, printed grid overlays, font licence cards; test printer + colour-correct viewing. Attendance ≥ 6/8; gate passed; package filed; feedback form before certificate.

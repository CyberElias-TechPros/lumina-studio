## 10–25 · Teaching block

**Colour, sanely.** Wheel: complement (opposites, high energy), analogous (neighbours, calm), split-complement (accent pop), triad (bold trio).
Values: 60-30-10 rule (dominant-secondary-accent). Meanings flex by culture — red = celebration/danger depending on room; green + gold reads "agriculture/Naija flavour" locally for some brands; check with the client's crowd, not your TikTok feed.

**Typography.** Categories (serif = authority/print-heritage; sans = clean/modern; slab = poster punch; script = invitation — NEVER body text; display = headlines only).
Pairing rule: ONE display + ONE text face, max two families, contrast pair (e.g. bold slab display + quiet sans body), never two similar-but-not-same (the uncanny valley of type).

**Text that reads.** Body ≥ 9pt print / ≥ 16px web; line-height 1.4–1.6; measure 45–75 characters; left-aligned for body (justified rivers badly); ALL CAPS = labels/acronyms, never paragraphs; underline = links, not emphasis; emphasis = weight or colour.

## 25–45 · Guided demonstration

Live: instructor builds a "colour story" for a fictional jollof joint (terracotta 60, deep green 30, gold 10) on the wheel; pairs it: slab display ("BIG CHOP") + clean sans body; sets 12pt/1.5 body; prints sample card.

## 45–70 · Guided practice

Pairs: **font duel** — pick display+text pairing for three briefs (law firm / children's party / phone-repair WhatsApp flyer); defend aloud; class votes pairings that "feel right" per audience.

## 70–95 · Independent practice

## Answers — KC2

1. 60 dominant surface, 30 secondary, 10 accent pop. 2) Opposites = energy; neighbours = calm. 3) Two families max, display + text. 4) ≥9pt print, ≥16px web. 5) Script = invitations/accents only, never readable-body — legibility dies.

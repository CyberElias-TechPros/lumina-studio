## 0–10 · Review & warm-up

Signboards decoded — two students found the "just print the logo bigger" crime; room applauds.

## 10–25 · Teaching block

**Workspace anatomy.** Template library (starting point, NOT the finish — every template is someone else's taste) · canvas (custom dimensions: A4 210×297mm, IG post 1080×1080, story 1080×1920, flyer 90×50mm card) · left rail (elements, text, uploads, backgrounds, brand) · right panel (properties: position, size, rotation, transparency) · top bar (resize, download, share, present) · elements (shapes, lines, frames, grids, icons).

**Template-to-original drill.** Find → duplicate → purge identity (their logo = out) → swap colours to YOUR 60-30-10 → swap type to YOUR pairing → swap image to YOURS → re-hierarchy. 80% "templated" is where amateur dies; this drill is where it dies.

**Export discipline.** PNG (web, transparent if needed) · JPG (photos, small) · PDF Print (file/print with bleed) · PDF Standard (screens) · MP4 (animations) — size by platform, not by default.

## 25–45 · Guided demonstration

Live: IG post from template A → original; IG story version; A4 flyer re-crop; PDF Print export with crop marks; download-twice comparison; instructor names the two beginner mistakes aloud (low-res export for print; JPEG logo with white box instead of transparent PNG).

## 45–70 · Guided practice

Pairs: pick the same template → two originals using own 60-30-10s and pairings; compare on screen side-by-side; write three swap differences.

## 70–95 · Independent practice

Solo: **brand kit card** — create your practice brand IN the tool: two colours saved, two fonts saved, logo wordmark set, one template-stamped layout saved. File screenshot to workbook.

## 95–110 · Correction & check

KC3: (1) Template rule. (2) Three platform dimensions. (3) Export for print = ? (4) PNG vs JPG one line each. (5) Transparency export trap.

## 110–120 · Summary & next session

Tools amplify judgment — they don't supply it. Next: deeper water layer by layer — brand kits and layers.

## Answers — KC3

1. Always start close to the target, then strip everything not yours. 2) Any three (1080×1080, 1080×1920, 210×297mm). 3) PDF Print (300dpi, crop marks) — never JPG-upscaled. 4) PNG = crisp graphics/transparency; JPG = compressed photos. 5) Logo-on-white box: export PNG with transparent background or it blocks the photo underneath.

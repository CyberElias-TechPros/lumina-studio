## 10–25 · Teaching block (briefing)

**Store reality (concepts only).** Google Play: $25 one-time, AAB bundle, review ~days · Apple: $99/year, App Store Review strictness, TestFlight for betas ·
requirements: icons (1024²), screenshots, privacy policy URL, targetSdk, content rating, data-safety form — READ the data-safety form honestly or rejections teach you.
**Alternative shipping.** Expo OTA updates for JS-only fixes · TestFlight/Play Internal Testing to real users before public · APK direct-install for pilot cohorts.
**Final project.** Your working v1 on device/emulator: cold-launch → complete job → see result, unaided, observed. Then the 3-minute defence: scope cut story, technical choice, the one bug that cost you the most sleep.

## 25–80 · Final demonstrations (observed)

Per student: core-loop run (cold launch, normal speed) · assessor pokes recovery paths (airplane mode; empty state; invalid input) · scores P1–P6 · room votes "would you install this?" — gauge only, not grade.

## 100–110 · Correction & check

KC8: (1) Play vs Apple cost. (2) AAB vs APK one line. (3) Data-safety honesty. (4) OTA scope (what updates over the air). (5) Beta path before public.

## 110–120 · Course close

## Answers — KC8

1. Play $25 once; Apple $99/yr. 2) AAB = Play's optimised delivery bundle; APK = raw installer. 3) Lies about collection = rejection or removal. 4) JS bundle/assets only — native changes need a new build. 5) Internal testing → TestFlight/Play beta → public.

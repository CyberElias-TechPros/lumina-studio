## Brief

Demonstrate, live, unaided:

1. Cold launch of your app on device/emulator.
2. The complete core job from your job story — e.g. search → pick → cart → receipt for a shopper app;
   register → log expense → see balance for an expense app — start to result without rescue.
3. One failure path shown gracefully (airplane mode, empty field, empty state).
4. The 3-minute defence: what you cut, what you kept, the bug that taught you the most.

## Conditions

Your build or your instructor-agreed variant; course notes allowed; nobody touches the keyboard but you;
≥20 seconds of calm silence at the start is fine — thinking is visible.

## Marking

CEA-ACA-QA-WEB-001 (P1–P6; gates P2 + P4, absolute). Show-and-tell: why this v1 and not the Instagram-shaped one in your head.

## Submission

Expo link or APK + repo URL + APK size screenshot to cohort file; portfolio within 7 days; feedback form before certificate.

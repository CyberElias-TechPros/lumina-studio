## What you will walk out with

A working multi-screen prototype of your own app — scoped to a sane v1, built with real navigation,
lists and storage, run live on a phone — plus the scope documents that stop your next idea dying in week three.

## The eight sessions

S1 Concepts & scoping (one user, one job) · S2 Mobile UI (flows, touch targets, platform conventions) ·
S3 Screens (toolchain setup, components, layout) · S4 Navigation & components (stack/tabs, reusables) ·
S5 State & data (input, lists, AsyncStorage) · S6 APIs (fetch, loading/error/empty, offline) · S7 Testing
(devices, emulator, debug) · S8 Publishing concepts + final project.

## Assessment weighting

KCs 10% · workbook 25% · A1 scope pack 15% · final prototype 40% · show-and-tell 10%.
Gate: core loop runs live, unaided.

## Classroom rules

Scope before code. One new thing per session. If the emulator misbehaves, the phone wins.

## 1. Identity

- **Title:** Web Design · **Department:** Web & Code · **Level:** Beginner
- **Duration:** 4 weeks · 8 sessions · 2/week · 105 min · **840 guided minutes**
- **Fee:** ₦50,000 · **Cohort:** max 15
- **Delivery:** On-site lab; machines with VS Code-class editors; live-server preview; test phones

## 2. Description

Domains to a live 3–5 page site you can send a client today: HTML structure, CSS (box model → flexbox →
responsive), the business section library (nav/hero/services/gallery/contact), UX/accessibility/SEO basics,
image optimisation — and publishing on a real URL.

## 3. Purpose

Most Nigerian SMEs have no web presence beyond a WhatsApp status. This course manufactures one done properly — written, styled, published, maintained-ish.

## 4. Audience

Beginners (no code needed) · SME owners · church/school media teams · career-switchers to front-end.

## 5. Entry requirements

Basic computer use; a browser; curiosity.

## 6. Learning outcomes

1. Explain domains, hosting, DNS and browsers in client language.
2. Write clean semantic HTML: headings, text, links, images, lists, tables, forms.
3. Style with CSS: selectors, box model, type, colour, flexbox, responsive layouts.
4. Build the standard business sections; test on mobile/browser; publish to a live URL.

## 9. Practical exercises

Homepage-anatomy teardown (S1) · save-as-HTML drills (S2) · colour-type trio (S3) · card grid flex (S4) · full section build (S5) · phone breakpoint lab (S6) · Lighthouse before/after (S7) · launch day (S8).

## 10. Assessment

| Component                                                   | Weight |
| ----------------------------------------------------------- | ------ |
| Knowledge checks (8 × 5)                                    | 10%    |
| Workbook practicals                                         | 25%    |
| Assignment A1 — published staging site (3 pages)            | 15%    |
| Final project — live 3–5 page business site on a public URL | 40%    |
| Show-and-tell — send your link, walk the mobile view        | 10%    |

**Critical gate:** the site loads publicly on its own URL in the assessor's browser (no localhost magic), renders on a phone, and has no dead links; failure = reassess once.

## 11. Critical behaviors

Validate before publish · test one real phone before one real client · never "my browser shows it fine" · alt text is kindness with SEO dividends.

## 12. Learning barriers

Perfection-paralysis ("not beautiful yet") — publish ugly, iterate; CSS cascade rage — the cascade is law, not opinion.

## 13–16. Delivery · QA · Resources · Completion

Free hosting (GitHub Pages/Netlify free tier); academy domain parking optional; image compressor taught. Attendance ≥ 6/8; gate passed; live link filed; feedback form before certificate.

## What you will walk out with

A live 3–5 page website for a real or fictional Nigerian business — yours to send to a client or an employer tonight — built semantically, styled responsively, checked on a phone, SEO-sane and up forever.

## The eight sessions

S1 How the web works (domains, hosting, DNS, browsers) · S2 HTML (structure, text, links, images, forms)
· S3 CSS fundamentals (selectors, box model, type, colour) · S4 Layout (flexbox, page skeleton) · S5 Business
sections (nav, hero, services, gallery, contact) · S6 Responsive (breakpoints, touch targets, real phones) ·
S7 Quality (UX, accessibility, SEO, images) · S8 Publishing (domain, hosting, launch).

## Assessment weighting

KCs 10% · workbook 25% · A1 staging site 15% · final live site 40% · show-and-tell 10%.
Gate: public URL loads on the assessor's phone.

## Classroom rules

Publish before pretty. Validate before showing. Ask the semantic-HTML question before the CSS one every single time.

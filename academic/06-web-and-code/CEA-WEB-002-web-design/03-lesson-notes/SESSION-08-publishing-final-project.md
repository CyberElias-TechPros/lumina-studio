## 10–25 · Teaching block (briefing)

**Hosting free tiers.** Netlify/Vercel/GitHub Pages — drag-drop folder or git push; HTTPS automatic; custom domain one DNS record away.
**Domain connection.** Buy at Nigerian registrars (.com.ng often ₦5–12k) · nameservers → hosting · `www` redirect · propagation up to 48h (usually minutes).
**Launch checklist (READ ALOUD).** ✓ HTTPS padlock ✓ all links clicked ✓ form tested end-to-end ✓ phone tested ✓ Google Business Profile claimed ✓ Search Console submitted ✓ sitemap.xml submitted ✓ analytics (even simple counter) ✓ backup of files in email/Drive.
**Final project.** Your complete 3–5 page business site on a PUBLIC URL — home, about, services, (gallery), contact — assessed by live load + phone render + link audit.

## 25–80 · Final demonstrations (observed)

Per student: load their URL on the assessor's phone (fresh browser, not theirs) · 5-page walkthrough · form-submit round-trip if live · link audit · Lighthouse number aloud · defence in 2 minutes: who is this site for, what would you improve with ₦50k.

## 80–100 · Debrief & close

## 100–110 · Correction & check

KC8: (1) HTTPS is free how? (2) DNS records you touch. (3) Pre-launch form test why. (4) Search Console purpose. (5) Backup rule.

## 110–120 · Course close

Certificates after public-URL gate. Post your link tonight — pride is the first client-management skill.

## Answers — KC8

1. Netlify/Pages/Vercel issue certs automatically. 2) A (or nameserver) + CNAME www. 3) Silent form failure = lost customers. 4) Tells Google you exist + fixes crawl errors. 5) Two copies, two places, always.

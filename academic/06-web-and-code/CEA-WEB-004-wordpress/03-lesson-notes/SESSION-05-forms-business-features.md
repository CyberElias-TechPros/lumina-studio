## 10–25 · Teaching block

**Contact forms.** WPForms/Formidable-class free tiers · required-name + phone · email notifications + SMTP plugin (or leads vanish into spam) · store submissions in dashboard · spam shield (honeypot > CAPTCHAs for small sites).
**WhatsApp integration.** wa.me/234XXXXXXXXXX?text=encoded-message deep link · floating click-to-chat button · click-to-chat in menus — Nigeria's default CRM.
**Basic e-commerce.** WooCommerce awareness: install → currency ₦ → Paystack/Flutterwave plugin for local cards/transfers/USSD · shipping flat rate · stock toggle · test mode ALWAYS before live keys.
**SEO + analytics.** RankMath/Yoast free: title/meta templates, sitemap.xml auto, Search Console connect. GA4 or Simple Analytics — one counter minimum; data you never check is decoration.

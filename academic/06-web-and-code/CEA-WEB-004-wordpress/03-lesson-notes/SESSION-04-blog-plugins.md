## 0–10 · Review & warm-up

Blog ideas read; the "why blog?" answered cold: Google refreshes rank by freshness; clients who read you trust you before the invoice.

## 10–25 · Teaching block

**Blog mechanics.** Posts with categories (structure — "Events", "News", max 6) + tags (keywords — "lagos", "catering") · excerpt · featured image · scheduling · sticky posts · comments moderation (Settings → Discussion: hold for approval).
**Plugins — casting call, not buffet.** For every itch, ask: does core do this? is it one job? last update <6 months? installs >10k? reviews alive? One excellent plugin > seven mediocre ones — the "plugin buffet" murders sites at dinner time.
**Safety & the five-question test.** (1) Updated recently? (2) Installs? (3) Reviews? (4) Support answers? (5) What data does it want? — fails any → find another.
**Conflicts — the autopsy.** Symptom (white screen, feature dies) → deactivate ALL plugins → reactivate one-by-one → last one in before the crash is the suspect → replace/alternative/report. Same for themes.

## 25–45 · Guided demonstration

Live: publish scheduled post "Lagos Wedding Packages 2026"; categorise; tags; comment held for moderation freed after review; plugin autopsy on pre-broken sandbox (contact form dead → culprit = ancient form plugin → replaced → feature restored).

## 45–70 · Guided practice

Pairs: publish + schedule YOUR practice blog post; one plugin install from the five-question test (SEO-class or caching-class); document the five answers on your workbook sheet; swap & audit each other's plugin choices.

## 70–95 · Independent practice

Solo: **blog + vetted plugin** — your post published/scheduled; one plugin installed legitimately with five-question evidence; comments moderated. File screenshots + plugin evidence sheet to workbook.

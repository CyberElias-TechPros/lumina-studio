## 0–10 · Review & warm-up

Five-page lists read; the room samples each: the recurring five are home/about/services/gallery/contact — because they convert.

## 10–25 · Teaching block

**Pages vs Posts.** Pages = evergreen business units (about, services, contact) — hierarchical, no date. Posts = dated entries (blog/news) — categories & tags, RSS.
**Block editor mechanics.** Type `/` to summon blocks (heading/paragraph/image/columns/button/group/cover) · patterns for instant sections · list view (⌘⇧O) for structure · drag-to-reorder · document outline.
**Reusable blocks.** Business hours, testimonial, CTA — build once, reuse on 5 pages; editing one updates everywhere.
**Menus.** Appearance → Menus (or Site Editor) · assign to Primary location · links to pages/categories/custom URLs · submenu hierarchy by drag-indent.
**Media library.** Upload once, insert many · alt text always · captions ok · never 8MB hero — compress first.

## What you will walk out with

A live, secure, backed-up WordPress site you could hand to a client today — installed by you, themed by you,
protected by backups and updates — plus the handover ritual that turns a build into a billing relationship.

## The six sessions

S1 Setup & dashboard · S2 Themes & customisation (child themes) · S3 Pages & the block editor ·
S4 Blog & plugins (safety, conflicts) · S5 Forms & business features (WhatsApp, basic e-comm, SEO, analytics) ·
S6 Security, backups & launch.

## Assessment weighting

KCs 10% · workbook 25% · A1 sandbox build 15% · final live site 40% · show-and-tell 10%.
Gate: live URL + working contact path + verified backup.

## Classroom rules

Backup before every change. Never nulled anything. The client gets written instructions, never vibes.

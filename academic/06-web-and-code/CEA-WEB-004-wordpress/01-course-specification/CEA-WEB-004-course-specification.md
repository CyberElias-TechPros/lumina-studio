## 1. Identity

- **Title:** WordPress · **Department:** Web & Code · **Level:** Beginner
- **Duration:** 3 weeks · 6 sessions · 2/week · 105 min · **630 guided minutes**
- **Fee:** ₦40,000 · **Cohort:** max 15
- **Delivery:** On-site lab; machines with browsers; a shared class WordPress install PLUS a personal practice sandbox where available; live client-host access optional

## 2. Description

From zero to a live, backed-up, secure multi-page WordPress site a Nigerian SME can actually run:
hosting & installation, theme customisation (safely), pages with the block editor, blog with categories/tags,
contact forms + WhatsApp integration + basic e-commerce, plugin safety, backups, updates — ending in launch and handover.

## 3. Purpose

WordPress powers ~43% of the web. It is the fastest route from "a client paid me to build their site" to "a client's site is live and bills are paid". This course teaches the working discipline, not just theme-clicking.

## 4. Audience

Beginners wanting a monetisable skill · freelancers · business owners who will maintain their own site · WEB-002 grads who want CMS speed.

## 5. Entry requirements

Basic computer & browser use; no code required; a free hosting account students create in-class.

## 6. Learning outcomes

1. Install and configure WordPress on real hosting (files, database, admin user).
2. Choose/customise a theme safely — child themes, and what breaks parents.
3. Build pages, menus, blog posts, contact forms with the block editor.
4. Evaluate plugins safely; diagnose conflicts; back up, update, secure.
5. Launch and hand over to a client — credentials, backups, maintenance plan.

## 10. Assessment

| Component                                                                                | Weight |
| ---------------------------------------------------------------------------------------- | ------ |
| Knowledge checks (6 × 5)                                                                 | 10%    |
| Workbook practicals                                                                      | 25%    |
| Assignment A1 — customised business home + contact page on sandbox, backup file produced | 15%    |
| Final project — live multi-page WordPress site with blog, menu, form, backups; launched  | 40%    |
| Show-and-tell — hand over to "the client" (instructor role-play)                         | 10%    |

**Critical gate:** the site must be reachable at a live URL, load a functional contact path, and the student must produce a verified backup file on demand; a localhost-only or unbacked-up "launch" fails the gate.

## 11. Critical behaviors

Backup before EVERY update · staging-test the risky plugin · never nulled plugins — ever · credentials handover written, not verbal.

## 12. Learning barriers

Plugin buffet (27 plugins, site dead by dinner) · nulled piracy culture · "it was working before the update" — backups or tears.

## 13–16. Delivery · QA · Resources · Completion

Shared class hosting or LocalWP-free practice; free host pairs with students; printed credentials-handover card. Attendance ≥ 5/6; gate passed; live URL + handover sheet filed; feedback form before certificate.

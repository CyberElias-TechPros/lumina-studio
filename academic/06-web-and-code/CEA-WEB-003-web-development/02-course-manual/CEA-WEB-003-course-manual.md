## What you will walk out with

A deployed, documented, version-controlled interactive website — planned, built, debugged and shipped by you — plus the Git workflow and portfolio presentation you can reuse on every future job.

## The twelve sessions

S1 Semantic HTML · S2 Forms & accessibility · S3 Box model & typography · S4 Flexbox/Grid responsive ·
S5 JS basics · S6 Functions/arrays/objects/loops · S7 DOM · S8 Forms validation & dynamic UI ·
S9 Project planning + Git · S10 Debugging & quality · S11 Deployment · S12 Portfolio presentation.

## Assessment weighting

KCs 10% · workbook 25% · A1 deployed interactive site 15% · final project 40% · show-and-tell 10%.
Gate: live URL, clean console, ≥1 self-coded interactive feature.

## Classroom rules

Type it yourself. Console first. Small commits. The deploy is the deadline.

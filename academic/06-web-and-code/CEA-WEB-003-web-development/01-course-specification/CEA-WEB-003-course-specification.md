## 1. Identity

- **Title:** Web Development · **Department:** Web & Code · **Level:** Beginner
- **Duration:** 6 weeks · 12 sessions · 2/week · 105 min · **1260 guided minutes**
- **Fee:** ₦60,000 · **Cohort:** max 12
- **Delivery:** On-site lab; machines with VS Code-class editors; browser DevTools; git installed; loaner phones

## 2. Description

The full arc from static pages to deployed interactive sites: semantic HTML, accessible forms, modern CSS (box model → flexbox/grid), JavaScript fundamentals, the DOM, form validation, project hygiene with Git, debugging, and the GitHub → deploy workflow — ending in a presented portfolio build.

## 3. Purpose

Web-design (WEB-002) ships brochure sites; this is the working carpenter's course — you leave with the craft, the tooling and the legally clean portfolio piece to job-hunt or freelance with.

## 4. Audience

Beginners ready for real programming · WEB-002 graduates · SME owners who want to maintain their own sites · future front-end developers.

## 5. Entry requirements

WEB-002 or equivalent HTML/CSS literacy; a laptop you control; willingness to type every example.

## 6. Learning outcomes

1. Write semantic, accessible HTML and maintainable CSS with flexbox and grid.
2. Program JavaScript: variables, types, operators, conditions, functions, arrays, objects, loops, events.
3. Manipulate the DOM: selecting, changing content/styles, event listeners, form validation, modals.
4. Structure projects properly; debug with DevTools; version with Git; deploy live.
5. Present and document the final build like a professional.

## 9. Practical exercises

Multi-section site (S2) · responsive conversion (S4) · interactive webpage (S6) · interactive form/calculator (S8) · repo init + first push (S9) · DevTools bug hunt (S10) · staging → production deploy (S11) · portfolio presentation (S12).

## 10. Assessment

| Component                                                       | Weight |
| --------------------------------------------------------------- | ------ |
| Knowledge checks (12 × 5)                                       | 10%    |
| Workbook practicals                                             | 25%    |
| Assignment A1 — planned + deployed multi-page interactive site  | 15%    |
| Final project — complete site/app, GitHub → live URL, presented | 40%    |
| Show-and-tell — walk the build, defend the decisions            | 10%    |

**Critical gate:** the final project must be reachable at a public URL, load without console errors on the assessor's machine, and demonstrate at least one genuinely interactive feature the student coded themselves; a static copy of a tutorial fails the gate.

## 11. Critical behaviors

Code every demo yourself — watching is not typing · commit small and often · read the console before asking · ship the interaction, then polish.

## 12. Learning barriers

Tutorial-hell (coded nothing without a video) · console-blindness (never opens DevTools) · scope fantasy (six features, zero finished).

## 13–16. Delivery · QA · Resources

Node not required (vanilla track); git installed; Netlify/GitHub free tier; projector; loaner phones; printed cheat-sheets (box model, flexbox, events). Attendance ≥ 10/12; gate passed; live URL filed; feedback form before certificate.

# CEA Lab — Interactive Learning & Practice Lab

**Vision:** CEA becomes a learning institution with its own practical digital laboratory, not simply a course website with quizzes.

**Tagline:** Learn · Practice · Experiment · Assess · Build

---

## 1. The CEA Interactive Learning & Practice Lab

A collection of browser-based tools, simulators, playgrounds, exercises, quizzes, assessments, and project environments that students can use while learning — even when they don't have the relevant software installed.

**Learning loop:** Learn a concept → see a demonstration → practice in a tool → complete an exercise → take a quiz → pass a competency assessment → build a project.

## 4. Tool Design Standard

Every serious learning tool follows this anatomy:
1. Tool introduction — what it is and why it matters
2. Learn mode — explanation and guided examples
3. Explore mode — free experimentation
4. Practice mode — specific tasks
5. Challenge mode — test independent ability
6. Assessment mode — score competencies
7. Progress — track attempts and improvement
8. Export or save — preserve useful work

## 8. Quiz & Assessment System

**Assessment types:** Diagnostic Test, Lesson Quiz, Practice Quiz, Topic Test, Module Test, Mid-Course Assessment, Final Theory Exam, Practical Assessment, Project Assessment, Competency Assessment, Timed Challenge, Mock Exam, Certification Assessment, Instructor Assessment.

**Assessment levels:**
- L1 — Recall (terms, facts, definitions)
- L2 — Understanding (explain, interpret, identify)
- L3 — Application (guided tasks and exercises)
- L4 — Analysis & Troubleshooting (diagnose, select, explain)
- L5 — Creation & Mastery (build, design, solve independently)

**Question formats:** Multiple Choice, Multiple Select, Fill in the Blank, Matching, Ordering, Short Answer, Calculation, Image-Based, True/False, Code Completion, Code Output Prediction, Find the Error, Correct the Code, Identify a Component, Label a Diagram, Drag-and-Drop Placement, Scenario Decision, Simulated Task, File Submission, Project Submission, Oral Assessment, Instructor-Reviewed Response.

**Difficulty categories:** Beginner, Elementary, Intermediate, Advanced, Professional.

## 9. Challenge Arena

Challenge types: Daily, 5-Minute, Speed, Accuracy, Fix-It, Build-It, Debugging, Logic, Weekly, Course, Community, Final Boss/Capstone.

**Gamification:** XP, tool mastery points, streaks, skill badges, challenge completion, course achievement badges, milestones, level progression, personal bests, optional leaderboards, challenge history, portfolio achievements. Primary competition: against own previous progress.

## 12. How Courses, Tools, Quizzes and LMS Connect

1. LESSON — teach a concept
2. DEMONSTRATION — show how it works
3. PRACTICE TOOL — allow the student to perform the skill
4. QUIZ/ASSESSMENT — test knowledge and ability
5. PROJECT — apply several skills to produce something
6. COMPETENCY — demonstrate mastery of the learning outcome

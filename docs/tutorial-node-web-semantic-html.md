# Web Development, session 1 — Semantic HTML

Published at `/classes/web-development/semantic-html`.
Prompt: `docs/tutorial-master-prompt.md`. Reviewed 2026-09-26.

## Planning snapshot

- **Learner:** can use a computer. No assumed HTML. Career-changer or shop owner who wants a page, not a definition.
- **Roadmap:** Web Development, session 1 of 12. Forms are next. CSS starts in session 3. Web Design's "How the Web Works" is linked, not required.
- **Capability:** create `index.html`, open it in a browser, and hand over a semantic one-page shop site with headings, links, a list and a data table.
- **Assumptions:** Windows 10/11 and VS Code, Chrome or Edge. Mac is named, not given fake menu paths. No CSS this session.
- **Verified:** MDN html element page (lang, one root, doctype case). W3C validator URL. VS Code download URL. Live Server treated as optional because the marketplace listing can change.

## Self-review

- **They can now:** produce a plain semantic page and tell a file-extension failure from a path failure.
- **Likeliest confusion:** the page looks undesigned, so they add style attributes. The lesson forbids that on purpose. Session 3 has to pay the promise.
- **Caveat:** Go Live steps can drift. The required path is double-click and refresh.
- **Retest:** open the worked example in a browser before the next cohort. Do not treat the illustrations as screenshots.
- **Split?** No. Editor setup is the missing prerequisite for this node, not a separate course. Forms stay in session 2.

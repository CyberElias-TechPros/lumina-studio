# Node 1 — Understanding the Computer

Published at `/classes/computer-basics-typing/understanding-the-computer`.
Prompt: `docs/tutorial-master-prompt.md`. Reviewed 2026-09-26.

## Planning snapshot

- **Learner:** absolute novice. May use a phone daily. No assumed desktop skill.
- **Roadmap:** Typing & Computer Basics, session 1 of 4. Flyer course two; true novice entry. Microsoft Office is listed first on the flyer and tells true beginners to take this course first.
- **Final capability:** reach a Windows desktop, open one program, leave safely, and run a dark-screen check without opening the case.
- **Assumptions:** Windows 10 or 11, desktop or laptop, learner is allowed to shut the machine down. Mac is named as a variation, not taught click-for-click.
- **Concept order:** situation → four jobs → name the hardware → first boot → RAM vs storage → ports → desktop → open/switch/close → four ways to leave → version differences → small traps.
- **Practice time:** 60–80 minutes, plus one unsupervised return the same day.
- **Verified before writing:** Windows 10 end of support (14 October 2025 on Microsoft's Windows specifications page; lifecycle table says 15 October 2025). Windows 11 minimum 4 GB RAM / 64 GB storage. Hibernate path via Control Panel → Power Options. Fast Startup makes Shut down differ from Restart.

## Self-review

- **They can now:** name the four jobs, boot with one press, open Notepad from search, answer a save prompt, shut down, and stop a dark-screen diagnosis before the case.
- **Likeliest remaining confusion:** Fast Startup. The lesson says shut down is not always a full reset, and a first-day learner may not feel that difference. Restart is the concrete rule to keep.
- **Environment caveat:** menu labels for Hibernate and Fast Startup move. The Control Panel path is the stable one taught. Re-check it if Windows changes that panel.
- **Retest before calling the screenshots done:** these are diagrams. Do not replace them with a Windows capture without labeling the version.
- **Split?** No. Ports, login, and shutdown are one arrival-and-departure skill. Keyboard detail correctly waits for session 2. Files and saving wait for the files session; this lesson only teaches why the save question appears.
